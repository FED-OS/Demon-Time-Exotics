# Seeded thread: first poll (Polls)

Title: **😈 Poll demo: which surface should get the next big feature push?**

A poll that decides something real, so the category's first visitor sees what voting here is *for* — not a vibes check, a steering input.

**The decision this poll informs:** the monorepo maintains four surfaces — landing, Tauri, Electron, mobile — from one spine, and the roadmap (ROADMAP.md) holds candidate features for each. The next big feature push lands on whichever surface the community actually uses, because shipping to a surface nobody's on is effort spent where it doesn't count. The owner makes the final call on brand and platform strategy (that's GOVERNANCE.md's structure, and the poll respects it) — but which surface the community lives on is exactly the kind of input that should steer.

**The options, with what each vote means:**

**🔥 Landing site** — the always-on surface, served on GitHub Pages at `dtemoney448.github.io/demon-time-exotics/`. Vote landing if the browser is where you check in; the candidate work there is the live-stream embed section and richer content shelves off the `[Unreleased]` roadmap.

**🖥️ Tauri desktop app** — the light, native desktop shell. Vote Tauri if you want a permanent DTE window on your machine; the candidate work is member-only content gating and native notification polish.

**⚡ Electron desktop app** — the full-fat desktop app with the deepest integration surface. Vote Electron if you live in a desktop app and want the member gating and comment-section integration candidates to land there first.

**📱 Mobile app** — the Expo app, the always-in-your-pocket surface. Vote mobile if the phone is your main screen; the candidate work is push notifications for breaking drama and the dark/light toggle.

**How to vote and what happens next:** vote for the surface you *use*, not the one you'd theoretically like — the poll is measuring reality, not preference. When the poll closes, the results get cited in the decision post that announces the next push, win or lose: if mobile wins, the next release notes say "you voted mobile, mobile got the push." If the result is close, the closeness is itself the finding — it means the surfaces are balanced and the tiebreak goes to the roadmap's engineering order. Either way, the outcome lands in this thread, because a poll whose ending nobody reads is a poll that taught the community voting is theater — and this category exists to prove the opposite.

**One poll at a time.** This category runs one decision poll at a time so each one gets attention and a real ending; ideas for the *next* poll belong in Ideas, where they get refined like any other proposal.
