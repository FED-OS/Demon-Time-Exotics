If you reference the Demon Time Exotics monorepo in a paper, talk, or
project, cite the repository:

> Multi-platform creator ecosystem monorepo* [Computer software].

If you use the monorepo layout (landing + Tauri + Electron + Expo + shared
packages) in your own work, an acknowledgment is appreciated (not required
under MIT):

> (https://github.com/DTEMONEY448/demon-time-exotics), MIT License.
