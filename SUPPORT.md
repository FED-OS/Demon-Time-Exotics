# Support — Get Help 🆘

## 🚑 Something's Broken? (Bugs)

1. **Check existing issues first** — [Issues](../../issues) — your problem may
   already have a fix in progress.
2. **Still stuck?** Open a new issue with the
   **Bug Report** template ([.github/ISSUE_TEMPLATE/bug_report.md](.github/ISSUE_TEMPLATE/bug_report.md)).
3. **Include:** which app (`landing` / `tauri` / `electron` / `mobile`),
   your OS + versions, exact steps to reproduce, expected vs actual behavior,
   and screenshots/logs if you have them.

## 💡 Have an Idea? (Features)

Open a **Feature Request** with the
[feature_request.md](.github/ISSUE_TEMPLATE/feature_request.md) template.
Tell us the problem you're trying to solve, your proposed solution, and which
app(s) it affects.

## 🏥 Troubleshooting Quick Hits

- **Install fails** → check Node ≥ 20.18 (`nvm install`) and pnpm ≥ 9.12
  (`corepack enable`)
- **Tauri fails on Linux** → missing webkit2gtk system deps — see [INSTALL.md](INSTALL.md)
- **Electron sandbox error on Linux** → run with `-- --no-sandbox`
- **Expo can't find Android SDK** → set `ANDROID_HOME` (see [FAQ.md](FAQ.md))
- **Landing site unstyled via file://** → use `pnpm dev:landing`, not
  double-clicking `index.html`
- **Fresh start** → `pnpm clean && pnpm install`
